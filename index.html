Projetos

Projeto 1: Classificação e Resposta Inteligente de E-mails 🔗 GitHub

Aplicação web que utiliza NLP e IA para classificar e-mails recebidos e sugerir respostas automáticas (PT/EN). Inclui autenticação com login e logout, interface simples e integração com APIs de IA.

Projeto 2: Kanaro – Termo de Consentimento 🔗 GitHub

Sistema web desenvolvido para gerenciamento e assinatura digital de termos de consentimento para cerimônias de ayahuasca. Inclui cadastro de participantes, validação de dados e envio automático por e-mail.

Projeto 3: EcoLuz – Monitoramento de Consumo de Energia 🔗 GitHub

Aplicativo mobile em React Native para monitoramento de consumo energético residencial. Integra-se ao Supabase para autenticação e armazenamento, e conta com telas de histórico, gráficos e modo escuro customizado.
